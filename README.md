# 📌 Bridging Gaps for the Hearing Impaired – India 🇮🇳

## 🚀 Overview
This project aims to bridge communication barriers for hearing-impaired individuals in India using an AI-powered autonomous web agent.

It enables real-time conversion between speech, text, and sign language, making communication more accessible and inclusive.

---

## 🎯 Problem Statement
Millions of hearing-impaired individuals in India face challenges in:
- Understanding spoken communication  
- Expressing themselves to non-sign language users  
- Accessing digital and public services  

There is a lack of real-time, scalable assistive solutions.

---

## 💡 Solution
We developed an AI-driven autonomous web agent that:
- Converts speech → text → sign language  
- Converts text/sign → speech  
- Works in real-time on web platforms  
- Uses TinyFish API for automation and interaction  

---

## ✨ Key Features
- Speech-to-Text Conversion  
- NLP-based Text Processing  
- Sign Language Representation  
- Two-way Communication (Speech ↔ Sign/Text)  
- Autonomous Web Agent (TinyFish API)  
- Web-based Interface

## ⚙️ How It Works
1. User speaks → converted to text  
2. Text processed using NLP  
3. Converted into Sign Language (visual output)  
4. Reverse: text/sign → speech  
5. TinyFish agent automates interactions
